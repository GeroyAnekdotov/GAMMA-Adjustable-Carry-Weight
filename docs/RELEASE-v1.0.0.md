The first public release of GAMMA Adjustable Carry Weight for **GAMMA 0.9.5**.

- Adds a configurable **0–1000 kg** carry weight bonus through MCM, with 10 kg steps and a default of 0 kg.
- MCM saves the setting across restarts and applies it to existing saves.
- Includes English and Russian menus and a ZIP ready to install through Mod Organizer 2.

Install `GAMMA_Adjustable_Carry_Weight_v1.0.0_MO2.zip` in MO2, enable the mod, and open **MCM → GAMMA 0.9.5 Adjustable Carry Weight**. Select a bonus and click **Apply**.

GeroyAnekdotov tested the mod in-game. The documented Lua scripts in this release retain the same gameplay logic.
