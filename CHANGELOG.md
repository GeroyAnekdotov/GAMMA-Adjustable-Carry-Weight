# Changelog

## 1.0.0

- First public release for GAMMA 0.9.5 following in-game testing by GeroyAnekdotov.
- Documented every Lua function and added the MIT License and development credits. Gameplay logic is unchanged from 0.1.0.

## 0.1.0

- Added an English and Russian MCM slider for 0–1000 kg of additional carry capacity in GAMMA 0.9.5.
- Integrated with GAMMA's keyed weight modifiers to preserve its calculation when changing settings, loading and updating Strength or artefact perks.
- Added the MO2 package builder, LuaJIT integration checks and in-game test plan.
